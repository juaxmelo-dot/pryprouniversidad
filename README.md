# 🎓 Primer Proyecto Web – Universidad

Este fue mi **primer proyecto de desarrollo web**, creado como práctica para aprender la estructura básica de una página utilizando **HTML y CSS**.

## 📌 Descripción

El proyecto consiste en una página web estática diseñada con el objetivo de practicar:

* Estructura de documentos HTML
* Uso de etiquetas semánticas
* Estilos con CSS
* Colores, fuentes y márgenes
* Organización visual de una página web

## 🛠️ Tecnologías utilizadas

* **HTML5**
* **CSS3**

## 🎯 Objetivo del proyecto

Aprender los fundamentos del desarrollo web y comprender cómo aplicar estilos a una página para mejorar su apariencia y organización visual.

## 📂 Estructura del proyecto

```
📁 pryprouniversidad
 ┣ 📄 index.html
 ┣ 📄 style.css
 ┗ 📄 README.md
```

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio:

```bash
git clone https://github.com/juaxmelo-dot/pryprouniversidad.git
```

2. Abre la carpeta del proyecto.

3. Ejecuta el archivo **index.html** en tu navegador.

## 📚 Lo que aprendí

* Crear la estructura básica de una página web
* Conectar un archivo CSS externo
* Aplicar estilos a textos, contenedores y secciones
* Mejorar la presentación visual de un sitio web sencillo
